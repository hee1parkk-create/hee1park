# 후판 압연 공정 Scale 불량 원인 분석 (POSCO)

## 프로젝트 개요
# 목표 : 후판 압연 공정에서 발생하는 Scale(산화철) 불량의 발생 원인을 데이터 기반으로 규명하고, SOP(표준 작업 지침서)를 작성하여 공정 수율 개선에 기여하고자 함
# 배경: Scale 불량은 가열로 내 산화량 과다와 압연기에서의 Descaling 제거 실패가 복합적으로 작용함. 따라서 현장 공정 데이터를 분석하여 핵심 인자를 도출하고, 공정 조건을 최적화하기 위한 가설을 검증 할 예정.

## 프로젝트 주요 분석 내용
# 본 프로젝트는 데이터 전처리부터 모델링, 핵심 인자 도출까지의 엔지니어링 과정을 체계적으로 수행하였습니다.


# 데이터 정제| HSB 미적용 행 제거 | 비정상 공정 조건을 배제하여 분석의 노이즈 차단 |
# 전처리| 이상치 제거 및 파생변수 생성 | 공정 물리학(온도, 시간, 면적 등)을 반영한 도메인 특성 반영
# 차원 축소 | PCA (주성분 분석) | 공정 변수 간 다중공선성 해소 및 데이터 압축 |
# 불균형 보정| SMOTE (오버샘플링) | 불량 데이터 부족 문제 해결을 통한 학습 성능 향상 |

## METHOD
# 1. 8종의 분류 알고리즘 비교 (Logistic Regression, Random Forest, XGBoost 등)
# PCA(주성분 분석)**: 18개 수치형 변수를 7개 주성분으로 축소 (분산 95% 보존)
# 가설 검정: 7개 가설(H1~H7) 검정 및 시각화
# 평가 지표: ROC-AUC, 혼동행렬, 임계값 최적화를 통한 모델 성능 극대화

## Insight
# 데이터 로드 결과 HSB 미적용 시 불량률이 100%임을 확인. 이를 단순 노이즈가 아닌 '비정상 공정 조건'으로 정의하고 별도 분석하여, 모델이 '공정 변수' 자체의 영향력을 학습할 수 있도록 정제함.
# 핵심 인자 도출 : Feature Importance 및 의사결정 트리 분석을 통해 실질적으로 Scale 발생에 영향을 미치는 산화 에너지 지표(Heat/Soak Oxidation Index)와 온도 강하(Temp Drop) 인자를 도출.

## 📊 결과 요약
# 가설 검정: 공정 온도, 시간, Descaling 횟수가 불량률에 미치는 통계적 유의성 확인
# 개선 방향: 모델이 제시한 핵심 인자를 바탕으로 가열로 최적 온도 설정 및 적정 Descaling 효율 유지 전략 제언
